# AI-Powered Incident Classification and Routing System using Oracle APEX

## Overview
This project demonstrates an AI-Powered Incident Classification and Routing System developed using Oracle APEX and Oracle Database technologies.

The application is designed to streamline incident reporting, categorization, priority assignment, and workflow tracking through an interactive low-code platform.

The system enables users to submit incidents, classify issue types, assign priority levels, and monitor incident resolution status using reports and dashboard analytics.

---

## Key Features
- Incident submission workflow
- Incident category classification
- Priority-based incident tracking
- Status management system
- Interactive reporting interface
- Dashboard analytics and visualization
- Database-driven workflow automation

---

## Technologies Used
- Oracle APEX
- Oracle Database
- Oracle Cloud Infrastructure
- SQL

---

## Application Workflow
1. User submits incident details
2. Incident category and priority are assigned
3. Incident status is tracked through workflow stages
4. Reports and analytics dashboards visualize incident trends
